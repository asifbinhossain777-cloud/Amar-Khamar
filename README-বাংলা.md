# আমার খামার — Offline MVP

এই সংস্করণটি আপাতত সম্পূর্ণ স্থানীয়/অফলাইন ব্যবহারের জন্য। অ্যাপ খুললেই সরাসরি ড্যাশবোর্ড আসবে; Login, OTP, Firebase বা ইন্টারনেট প্রয়োজন নেই।

## বর্তমান MVP-তে আছে
- গরুর ট্যাগ/আইডি, নাম ও ধরন যোগ এবং তালিকা দেখা
- আয় ও ব্যয়ের এন্ট্রি
- দৈনিক কাজ/নোট যোগ এবং সম্পন্ন চিহ্নিত করা
- SQLite-এ ফোনের ভেতরে তথ্য সংরক্ষণ
- BDT (৳) হিসাব

## গুরুত্বপূর্ণ সীমাবদ্ধতা
- এই MVP-তে এখনো দুধ উৎপাদন, খাদ্য মজুত, চিকিৎসা, প্রজনন, ওজন, কর্মচারী, PDF/Excel রিপোর্ট এবং বহু-ফোন Sync সম্পূর্ণভাবে তৈরি হয়নি। এগুলো পরবর্তী সংস্করণে যোগ করতে হবে।
- ডেটা এই ফোনেই থাকবে। অ্যাপ আনইনস্টল বা ডেটা মুছে ফেললে ব্যাকআপ ছাড়া তথ্য হারাতে পারে।
- Login/OTP, Firebase এবং Cloud Sync ইচ্ছাকৃতভাবে এই সংস্করণ থেকে বাদ দেওয়া হয়েছে; পরে যোগ করা যাবে।

## Build
Android Studio-তে প্রজেক্ট খুলে Gradle Sync করে APK Build করতে হবে। `google-services.json` লাগবে না।
